04 — How I Build

I don't just want to build things. I want them to be useful.

  1. 01

    Find the problem

    Look for something people actually struggle with, instead of inventing a problem to justify a product.

  2. 02

    Build a working version

    Start with the simplest version that can demonstrate the idea.

  3. 03

    Test it

    Use the product, check what breaks, and find out whether it makes sense to other people.

  4. 04

    Improve it

    Make changes based on what I learn, instead of adding features just because I can.
